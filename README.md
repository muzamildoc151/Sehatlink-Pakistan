# SehatLink V3
V3 adds a patient request flow, demo case ID, doctor login/dashboard, case statuses, specialty selection, specialist directory search, and privacy/safety page.

IMPORTANT: This is a frontend prototype. The patient form does not transmit or store health information. The dashboard contains fake cases only.

Before accepting real patients: add a secure backend/database, authentication + MFA, role-based access, audit logs, encryption, payment verification, consent/privacy process, emergency escalation, verified doctor/hospital directory, and appropriate professional/legal review in Pakistan.

GitHub Pages: upload all files to repository root, then Settings -> Pages -> Deploy from branch -> main -> /(root).
